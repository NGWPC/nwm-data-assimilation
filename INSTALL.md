# Installation instructions

- Clone the repository into your local workspace: git clone https://github.com/NGWPC/nwm-data-assimilation.git
- Create and/or activate your python virtual environment.
- Navigate to the repository root: cd nwm-data-assimilation
- Install the package dependencies: pip install -e
- Use the `postprocessing_wrapper_sample.py` to test post-processing routines for NWM output variables.
